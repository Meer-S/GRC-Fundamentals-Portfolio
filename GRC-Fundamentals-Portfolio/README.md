## 📌 Project 2: ISO 27001 Gap Analysis
**File:** `02-ISO27001-Gap-Analysis/Project2_ISO27001_Gap_Analysis.xlsx`

- Conducted a gap analysis against ISO 27001 controls.
- Identified areas of non-compliance and improvement opportunities.
- Delivered actionable recommendations for certification readiness.

**Sample Extract (Markdown Table):**

| Control ID | Requirement                  | Status   | Gap Identified             | Recommendation                  |
|------------|------------------------------|----------|----------------------------|---------------------------------|
| A.5.1      | Information Security Policy  | Partial  | Policy outdated            | Update and approve new policy   |
| A.9.2      | User Access Management       | Missing  | No formal access reviews   | Implement quarterly access review |
| A.12.4     | Logging and Monitoring       | Partial  | Logs not centralized       | Deploy SIEM solution            |

## 📌 Project 3: NIST RMF Risk Assessment
**File:** `03-NIST-RMF-Risk-Assessment/Project3_NIST_RMF_Risk_Assessment.xlsx`

- Applied NIST Risk Management Framework (RMF) to assess organizational risks.
- Created a risk register with likelihood, impact, and mitigation strategies.
- Prioritized risks for executive decision-making.

**Sample Extract (Markdown Table):**

| Risk ID | Description                        | Likelihood | Impact | Rating   | Mitigation Strategy              |
|---------|------------------------------------|------------|--------|----------|----------------------------------|
| R-001   | Phishing attack on employees       | High       | High   | Critical | Awareness training + MFA         |
| R-002   | Vendor data breach                 | Medium     | High   | High     | Vendor risk assessment + contracts |
| R-003   | Misconfigured cloud storage bucket | Medium     | Medium | Moderate | Regular audits + automated checks |
